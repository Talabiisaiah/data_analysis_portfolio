# 👥 Adult Census Income Analysis – Excel Data Exploration

This project explores the **Adult Census Income dataset**, a foundational dataset in data analytics, to identify trends and patterns that influence whether an individual earns **more than $50K per year**.

Using **Microsoft Excel**, I performed a full exploratory data analysis (EDA) with pivot tables, charts, and formulas to extract insights around **age, gender, education, occupation, and income**.

---

## 📊 Project Objectives

- Analyze income distribution and identify demographic trends
- Understand the relationship between **age**, **education**, and **income**
- Explore gender-based income disparity
- Investigate weekly working hours and their link to income level
- Visualize key factors impacting high income earners

---

## 🧾 Dataset Overview

- Source: UCI Machine Learning Repository  
- Records: ~32,500 individuals  
- Target: `Income` — `<=50K` or `>50K`

---

## 🔍 Key Findings

| Question | Insight |
|---------|---------|
| **% earning > $50K** | **24.08%** of individuals earn more than $50K |
| **Average Age (>$50K)** | 44 years |
| **Median Hours/Week (>$50K)** | 44 hours |
| **Gender Breakdown (>$50K)** | 85% Male, 15% Female |
| **Correlation (Age vs Education-num)** | **0.0365** — Very weak positive correlation |

---

The Excel dashboard includes:

---

## 🧠 Conclusion

- Education alone does **not strongly correlate** with age in this dataset.
- High income earners tend to be **older** (average age 44) and work **more hours/week** (median 44).
- There is a **significant gender imbalance** in high income brackets.
