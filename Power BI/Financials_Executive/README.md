
# 💼 Executive Financial Overview Dashboard – Power BI Project

This project presents a comprehensive **financial performance dashboard** created using **Power BI**. The dashboard is designed to help executives, financial analysts, and business leaders monitor key metrics such as **sales**, **profit**, and **profit margin** across **segments, products, countries, and time**.

---

## 🧾 Project Overview

**Objective**: To create an interactive executive dashboard that delivers clear financial insights across business dimensions such as **segment**, **product line**, and **geography**.

**Tool Used**: Microsoft Power BI

**Data Type**: Financial and sales data from a global organization

---

## 📊 Key Metrics Tracked

| Metric | Description |
|--------|-------------|
| **Total Sales** | $118.73M – all-time sales revenue |
| **Total Profit** | $16.89M – total profit generated |
| **Average Profit Margin** | 27.90% – across all segments and products |
| **Units Sold** | 1.13M – total quantity sold |

---

## 📈 Dashboard Features

### ✅ Sales Trends
- **Total Sales by Month** (Bar Chart): Understand sales seasonality and monthly performance
- **YTD Sales by Year**: Compare year-to-date totals across 2013 and 2014
- **MTD Sales by Quarter**: Month-to-date analysis segmented by quarter

### ✅ Segment & Product Analysis
- **Sales and Profit by Segment**: Government, SMB, Enterprise, etc.
- **Sales by Product**: Highlights top-performing SKUs like PASEO, VTT, VELO
- **Profit Margin by Product**: Profitability ratio visualization

### ✅ Geographic View
- **Sales by Country**: Analyze regional sales distribution (Canada, US, France, etc.)

### ✅ Slicers for Interactivity
- Filter dashboard by:
  - **Year**
  - **Month**
  - **Country**

---

## 🛠️ Tools & Techniques Used

- Power BI Desktop
- DAX measures and calculated fields
- Slicers and visual interactivity
- KPI cards for executive insights
- Multi-page layout with clean visual hierarchy

---

## 📌 Key Insights

- 📈 Sales surged in 2014, reaching $92M compared to $26M in 2013
- 🏢 The **Government** and **Enterprise** segments are the top revenue drivers
- 📊 Products like **PASEO**, **VELO**, and **MONTANA** lead in both sales and margin
- 📉 Some products report unusually high margins (>2000%), which may require cost validation
